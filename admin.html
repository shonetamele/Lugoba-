1. Link YouTube channel (automatic live)

Link the church YouTube channel once. When you press Go live on YouTube, the website Live page shows that stream automatically — no copying links every service.

Find it: YouTube Studio → Settings → Channel → Advanced settings → Channel ID. It always starts with UC. Not your @username.

Two-way flow:
• Link channel once → when YouTube is live, the website Live page shows it.
• Press Go live on YouTube now → opens YouTube Studio so you start the stream there; the website picks it up automatically. Browsers cannot push camera video to YouTube by themselves — YouTube Studio (or the YouTube app) must start the broadcast.

Optional fallback (only if you prefer a one-off link):

2. Record & store on Cloudinary

Capture camera or screen from this device, record the service, then upload the file to Cloudinary automatically.

Ready.

Uses your browser MediaRecorder. Allow camera/mic permissions when asked. Keep this tab open. Cloudinary's free plan rejects videos over 100 MB, which is roughly 5–6 minutes at HD — for full services, let YouTube record the stream and paste its link in step 3.
